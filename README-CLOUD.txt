VIRAL STUDIO CLOUD RENDER V8.0

Objetivo: gerar vídeos no celular sem Motor PC.

Deploy recomendado:
1. Crie um serviço Docker no Render/Railway/Fly/VM.
2. Faça upload desta pasta/repositório.
3. Garanta disco temporário suficiente (ideal 10 GB+).
4. Aponte VS_RENDER_SERVER_FALLBACK em app.js para a URL HTTPS do serviço.

O frontend já usa Cloud-first. O endereço atual continua https://viral-studio-motor-cloud.onrender.com até você publicar/substituir o serviço.

Observação: a voz neural usa edge-tts e precisa de saída à internet.
